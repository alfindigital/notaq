# Notaq — Aplikasi Catatan Cepat

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript)](https://typescriptlang.org)

Aplikasi catatan ringan dan cepat. Tulis, simpan, dan akses catatan kapanpun. Semua data tersimpan lokal di browser — tanpa login, tanpa cloud, tanpa biaya.

---

## Fitur

- 📝 **Catatan Cepat** — Tulis dan simpan dalam hitungan detik
- 🏷️ **Organisasi** — Kategorisasi catatan dengan tag/label
- 🔍 **Search** — Cari catatan dengan cepat
- 💾 **Local-first** — Data di browser kamu, tidak ke mana-mana
- 📱 **PWA** — Installable, bisa dipakai offline
- 🌙 **Dark Mode** — Nyaman di malam hari

---

## Quick Start

```bash
git clone https://github.com/alfindigital/notaq.git
cd notaq
npm install
npm run dev
npm run build
```

---

## Stack

- TanStack Start + TypeScript 5
- Tailwind CSS + shadcn/ui
